How it works

  1. 1

    Pick the vulnerability

    Each one has its own scanner, built for exactly that problem.

  2. 2

    Enter your website

    The scanner loads your start page once, the same way a browser does.

  3. 3

    Get a plain answer

    Affected, patched, or not visible from outside, plus what to do next.

Run it yourself

Every scanner is open source and a single Python file. No install, no dependencies, no limits: scan your own servers, whole IP ranges and every vhost on them.
