How it works

  1. 1

    Pick the vulnerability

    Each one has its own scanner, built for exactly that problem.

  2. 2

    Enter your website

    The scanner loads your start page once, the same way a browser does.

  3. 3

    Get a plain answer

    Affected, patched, or not visible from outside, plus what to do next.

shouldipanic.ch, open-source checks for current web vulnerabilities. Only check websites you own or have permission to check.
